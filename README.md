# ARCSTUDIO AI — Public Media Host

This repository hosts only final, approved, publicly shareable media assets for ARCSTUDIO91.

## Publishing rules
- Upload only final assets explicitly prepared for public Instagram publishing.
- Never upload source credentials, private client files, personal data, drafts, or internal production notes.
- Keep each daily package in a dated folder: `YYYY-MM-DD/`.
- Use stable raw GitHub HTTPS URLs for Buffer media only after verifying anonymous access and the returned media MIME type.
- Keep the feed image, carousel slides, and Reel as separate files. Preserve carousel order in filenames.
- A successful GitHub commit is not proof that Buffer can fetch the asset; verify each raw URL before queueing.

## Intended use
This repository is a public static file host for ARCSTUDIO91-approved Instagram media. All content added here is considered public.
